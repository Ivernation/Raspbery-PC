# RASPBERRY PI PC

Hello Stardance 👋 I've always wanted to build something like this, I'm really grateful that you gave me the chance to make it happen :D You see this is a custom sort of pc powered by the RASPBERRY PI 5. It's a perfect option as its practically build for the role and powerful enough to run Linux. The pc will contain things like...


   🖥️ 7" touchscreen
   
   🧠 Raspberry Pi 5
   
   📷 IR-capable camera
   
   ⌨️ External keyboard
   
   🖱️ External mouse
   
   🔌 12V wall-powered
   
   🖨️ 3D-printed enclosure


The screen will be on a separate mount it's the one that that will that will contain things like the speakers, microphone, camera and the display of course. It will be connected to the pc with an HDMI cable. This also means the pc can connect to any other display that supports HDMI input just like any regular pc would!
